# MVP · MiArchivos

## Resultado mínimo
Explicar qué ocupa espacio y cómo está organizado un directorio autorizado.

## Aceptación
- tamaño por carpeta/archivo;
- top de elementos grandes;
- errores de permiso no rompen el recorrido;
- no modifica ni borra;
- symlinks/reparse points se manejan sin loops;
- reporte JSON común.
